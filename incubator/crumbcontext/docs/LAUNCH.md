# CrumbContext launch sequence

## Public claim

> Give every AI the context it needs—not the entire conversation.

Lead with the screenshot-ready report generated by `crumbcontext demo`, but label token figures as deterministic estimates until a real provider counterfactual benchmark is published.

## Demonstration

```bash
pip install -e .
crumbcontext demo --out demo
open demo/report.html
```

The launch proof should show:

- original versus routed token estimate;
- exact anchors protected;
- every block's lane and reason;
- generated PNG, CRUMB, summary, and sidecar artifacts.

## Release gates

- all tests pass;
- exact-anchor fixture is 100% preserved;
- authority fixtures never leave `exact`;
- benchmark methodology is reproducible;
- README does not claim provider-billed savings without measured counterfactuals;
- repository description and topics are filled in;
- 30-second terminal demo is recorded.

## Distribution

Post the problem first: long agent sessions resend stale context and exact identifiers can be corrupted by lossy compression. Follow with the open-source solution, reproducible demo, and direct GitHub link. The product should be understandable from one screenshot and one command.
